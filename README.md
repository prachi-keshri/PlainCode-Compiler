
# PlainCode Compiler

## Project Title
PlainCode: Design and Implementation of an
English-Like Programming Language Compiler

## Overview
PlainCode is a custom English-like programming language
that is translated into C using a compiler built in C++17.

The compiler implements lexical analysis, syntax analysis,
AST generation, semantic analysis, intermediate code
generation, optimization, and C code generation.

## Technology
- Implementation: C++17
- Source Language: PlainCode
- Target Language: C
- Development Environment: VS Code
- Target Compiler: GCC

## Sample PlainCode Program
    SET a TO 10
    SET b TO 20
    SET result TO a + b * 2
    DISPLAY result

Expected final execution output: 50
